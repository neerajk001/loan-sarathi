# Backend Server

This is the Express.js backend for the Loan Sarathi application.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Environment Variables:
   The `.env` file should be populated with `MONGO_URI` and `PORT`.
   (Already created).

## Running

- Development:
  ```bash
  npm run dev
  ```
- Production:
  ```bash
  npm start
  ```

## API

- Base URL: `http://localhost:5000`
- Gallery: `/api/gallery`
