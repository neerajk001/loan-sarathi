# Loan Sarathi Project

This repository contains the source code for the Loan Sarathi application, organized into frontend and backend services.

## Structure

- **frontend/**: Next.js application (React)
- **backend/**: Express.js application (Node.js)

## Getting Started

### Quick Start (Both)
1. Run the following command in the root directory:
   ```bash
   npm run dev
   ```
   This will start both the backend (port 5000) and frontend (port 3000) concurrently.

### Backend
1. Navigate to the backend folder:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm run dev
   ```

### Frontend
1. Navigate to the frontend folder:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm run dev
   ```
